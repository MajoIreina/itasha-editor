## 自动同步

保留 `tools/git-auto-sync.ps1` 和现有用户级任务。它遵循新的忽略规则，后台提交未忽略的源码修改并推送上游，不改写远端历史。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/git-auto-sync.ps1 -Install
powershell -NoProfile -ExecutionPolicy Bypass -File tools/git-auto-sync.ps1 -Uninstall
```

日志位于 `%LOCALAPPDATA%/ItashaEditor-GitAutoSync/sync.log`。整合期间暂时停止任务，推送验证后恢复。不要推送本机归档分支或使用 `git push --all`，以免重新上传历史试验对象。
