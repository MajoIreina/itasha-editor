# 仓库与目录约定

当前主线为 Rust + Electron。新增业务按 `docs/模块架构.md` 的职责归属进入独立模块，宿主代码只维护 `desktop/src/`，生成的 `desktop/electron/resources/app/` 不手工修改。

## Git 内容

提交源码、依赖锁文件、配置、车型适配数据、示例、测试工具与文档。`app/paint-surfaces.json` 和 `app/surface-guides.json` 是编辑器使用的轮廓数据，随源码版本管理。

下列内容由 `.gitignore` 排除，仍保留在本地：

- `projects/`、`exports/` 和浏览器设置、日志、会话文件；
- `backend/target/`、`desktop/node_modules/`、`desktop/electron/`、`desktop/native/`；
- `resources/data/`、`resources/ui/`、离线捕获清单及 `vehicles/data/`；
- `development/` 中的下载包、旧实现归档、基线和发布产物；
- 自动化生成的 `tools/acceptance/`、历史验证 JSON 与截图。

大型车型资源通过本地存档单独恢复，仓库不使用 Git LFS 保存这些资源。示例的源文件位于 `examples/`，构建时只补齐缺失示例，不覆盖用户工程。

## 本地整理

旧 Python 后端、WebView2 DLL / 声明、C# 宿主与安装器、旧解码和迁移工具归档到 `development/legacy-webview2/source/`，旧截图归档到 `development/history/`。这些历史文件只供比对，保留原路径假设，不作为当前版本的构建入口。旧运行时和浏览器数据不删除。

项目根目录保留当前启动入口、使用说明和仓库配置。测试图片集中在 `tools/fixtures/`。历史比较与独立调试工具需要依赖时统一使用 `desktop/node_modules/playwright-core`，不引用某台电脑的用户目录。

## 提交前

```powershell
git status --short
git diff --check
node --test desktop/test/*.test.cjs tools/test/*.test.cjs
node tools/surface-curvature-acceptance.cjs
```

涉及渲染、拾取或曲面时，按构建文档运行真实车辆回归。性能脚本单独执行。不要强制添加用户工程、会话或生成目录；原始车型资产也不随源码推送。
