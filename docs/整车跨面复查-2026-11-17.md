## 实际发现与处理

1. **物理比例错误**：原传播把 chart 的拉伸/剪切带入素材尺寸，300 mm 素材可形成约 2646 mm 的传播半径，绕到车辆另一侧。改用世界三角形的真实毫米和 Jacobian 的正交方向因子，尺寸、抓取偏移与缩放使用同一框架。2D 控制框、命中、旋转、键盘移动以及原生抓取/焦点同步调整。
2. **左下翼子板错误配对**：v24 的最近质心镜像为多对一，还存在双重 UV 顶点置换。1770 片只对应 1276 个独立源面，不能证明左面完整。新图按真实左侧 source face、UV0 和原评审范围构建；镜像近邻脚本仅保留历史复现用途。
3. **真实漆面缺口**：补回尾厢外板、充电盖外向区域、门板和后保险杠的已确认缺口；按逐 source face 的多边形并集处理重复和缺失，保留 v21 评审遮罩。对非保护源边进行共边细分，730 条原显式跨部件接缝保持可追溯。另增 49 处同部件原始 GLB 共边传播关系（46 处共享索引边、3 处 UV 分裂但 POSITION 相同的边）；仅在真实遮罩共同支持区与素材相交时传播，目标仍逐片裁剪。
4. **极薄碎片与错岛**：收紧碎条的 source bary 共线/去重条件，避免固定空间容差造成边界折返；稳定 chart 拟合与紧凑分岛避免远距离 UV 重叠。同一原始源面通过稳定兄弟片的完整双精度仿射恢复几何和方向，避免微片世界法向的量化误差。
5. **错误共边与真实数值窄缝**：原 1 微米世界坐标哈希把两条不同的约 0.24 微米边误焊，使整张素材偏转约 92°。同一源面改用精确归一源重心端点识别共边；同时检查实际覆盖，不能靠 730 条外部接缝全绿掩盖尾厢内部 T 形切边断链。同一原始源面、同一部件的已保留遮罩共享源面切平面，素材可延伸到其中的另一片；世界位置逐顶点须与原片一致到 5 微米以内。输出仍逐片裁剪，不补桥接域、不往遮罩孔洞出片，不按距离焊接无关源面。稳定参考片在图片范围外时，也须能到达图片范围内的其他保留片。
6. **面积阈值丢片**：移除生成器按 piece 面积、UV 面积及任意世界面积阈值删除真实正面积片的路径；UV 退化用源面切平面微 chart 保留。运行校验以 f32 世界端点转双精度后的真正零叉积拒绝退化片，真实不可表示部分逐片列出，不称作已覆盖。源重心用完整齐次行列式判定正域；对规范化后近共线的微片，方向由稳定原源面及其 UV 梯度恢复。修复前充电盖微片曾出现约 33.68° 轴偏差，现纳入硬回归。原生 ray 拾取改用双精度和相对平行判定，移除按三角面积排除微片的固定阈值。
7. **旧工程安全迁移**：更换地图按旧 fragment ID 恢复源面重心，再定位新片；保持世界位置、物理尺寸和图片轴。当前文档及所有撤销/重做历史必须全部成功才一次提交。错误背面锚点、不可表示的 packed chart 锚点或旧图缺失会明确拒绝，不自动吸附或仅改指纹。node175/source32590 位于左前部，旧后保险杠误收的两片按唯一显式源面规则迁入前左翼子板；仍须通过位置和图片轴校验。

8. **倾斜后保险杠的观察方向**：整车 GPU 专项发现“定位素材”在法线竖向分量较大时强制使用固定俯视方位，相机移到后保险杠前侧并被尾翼/尾厢遮挡。现保留局部外向法线的水平方位，仅近纯竖直时回退到部件方位；增加实际 Camera::eye 回归。专项同时等待当前文档和选中帧实际提交后再聚焦，避免把先前重绘当作新相机见证。`renderedRevision` 和相机状态只在 `gpu.frames` 确实增加后发布；交换链暂时跳帧保留 dirty 重试。

9. **2D 二次归一化压扁微片**：原始 packed UV 全部为正，但遮罩流用 f32 除以部件宽高后，尾厢有 8 片变成零面积。2D 遮罩改为先提升到 f64 再归一化，按 little-endian f64 传输并由 Float64Array 解码；GPU 世界几何和原图不改。逐片检查实际 IPC 遮罩的有限性、数量和正面积，不用忽略微片来通过。
