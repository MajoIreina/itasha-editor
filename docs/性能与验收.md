# NEXT 性能与验收

当前验收对象为重构 NEXT；旧 Electron 0.2 的检查数量和计时仅为历史参考，不继承为 NEXT 的验证结果。

2026-11-18 最新修复、源面完整性审计、物理毫米和真实 GPU 验收见 [整车跨面复查](整车跨面复查-2026-11-17.md)。当前运行地图为 manifest 指定的 v25 verified；跨面回归保留原越侧传播断言。

同日 [主线切换](NEXT主线切换-2026-11-17.md) 和 [结构整理](结构整理-2026-11-17.md) 记录修复前的 79 通过、1 失败及桌面 35 项通过，作为历史证据保留。不能用这些旧结果代替新地图与算法验收。

常规静态/算法检查见 [开发与构建](开发与构建.md)。真实桌面 smoke 启动构建后的 Tauri 和原生 wgpu，使用独立临时工程目录；GPU readback 图像不能单独证明操作系统窗口合成与肉眼颜色一致。

涉及素材传播、拾取、着色器、材质或场景的改动，需重跑相应真实车辆回归并人工核对证据。性能结论必须记录设备、画质、分辨率、车型包指纹和实际工作负载。

本轮没有重新测量完整性能矩阵，也不宣称施工导出、车型全适配或发布验收通过。仍待完成：其他车型完整适配、旧 `.su7design` 格式迁移、施工导出、自动保存、安装器以及 DPI/多屏/电源与发布矩阵。按具体改动更新清单，不以“模型能显示”代替完整编辑验收。
