# NEXT 接口与车型适配

React 通过 Tauri bridge 读取 Rust 快照并提交命令；命令定义与权限以 `next/src-tauri/src/main.rs`、`build.rs` 和 `capabilities/main.json` 为准。核心操作包括 read_view、execute、close_clean、choose_directory、import_image/asset_bytes，以及 viewport_* 原生视口命令。

Rust 使用工程 ID、session epoch 与修订防止过期操作；图像和几何通过受限资源句柄或二进制 IPC 传输。前端不传任意模型路径作为业务文件访问接口。

## 车型边界

- `next/catalog/vehicles.json` 提供车型与基础选配；目录来源是根 config/vehicles 的数据。
- 当前原生模型适配在 `next/src-tauri/src/model_package.rs`，仅接入 SU7 Max；其他车型的目录入口不代表模型已实现。
- 基础四轴为车漆、轮组、内饰、方向盘。黑化套装和碳纤维等独立轴按具体车型后续接入，不能宣称当前已完成。
- 通用渲染器保留在 renderer crate，车型差异进入适配层。不得把 SU7 网格、材质、尺寸、坐标和哈希直接复用于其他车型。
- 原始模型、解密原件、兼容修复与软件导出分别保存；资源处理优先使用本地小米适配技能。
