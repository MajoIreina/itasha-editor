# NEXT 主线切换与验证记录

日期：2026-11-17（Asia/Hong_Kong）。版本保持 `0.3.0-dev.6`。

## 主线决议与范围

用户指定：整理现有 NEXT，对 GitHub 原项目进行替换，此后开发按照重构后的 NEXT 进行。应用工作区保持 `next/` 相对路径，架构为 Rust + Tauri 2 + React/TypeScript + wgpu。

根 README、启动脚本、使用说明、架构/构建/资源/验收文档及 AGENTS 已统一指向 NEXT。旧 Electron 应用源码与旧验收链路退出当前 Git 树，本机旧文件和原始资源保留。车型来源 registry/adapters 仅供生成 NEXT 目录使用。

本次保留当前 v24 运行地图、v21 兼容回归和 v15 布局尺寸报告。历代未封口地图、Blender、scratch、用户数据和生成输出均排除。文件清单与 SHA-256 见 [漆面 manifest](../next/assets/paint/manifest.json)。

## 历史保全与提交方式

切换前本地 HEAD：`e58833cc5761b1f0e1ae0312404910f40fae1a63`。远端旧主线：`fa0733d34f603629a2936cc83557e2f92a91ac5a`，没有分叉。

本地 17 个自动同步提交混入历史大地图，其中两个未封口 JSON 超过 100 MiB；此前自动推送被远端拒绝。因此保留本地归档分支和经 verify 校验的完整 history.bundle，从远端旧主线构造干净的替换提交，普通 fast-forward 推送，不改写既有远端历史。

本机归档路径和恢复命令见 [仓库管理](仓库管理.md)。这不是原始资源与用户数据的全量备份；本轮没有删除这些内容。

## 为独立开发所做的修复

- Playwright 1.58.2、pngjs 7.0.0 作为 NEXT 固定版本 devDependencies，更新锁文件。
- 5 处桌面测试导入改用 NEXT 自己的包名，不再引用旧 `desktop/node_modules`。
- 4 个 smoke 支持 `ITASHA_MODEL_ROOT`，缺省按 NEXT 相对目录 `../../3D` 解析，移除硬编码模型盘符。
- 补齐属性和整车布局的 package scripts；核心 Rust 测试使用 `--locked`。
- 修正 topology.rs 两处 rustfmt 换行，不改变曲面传播算法或断言。

## 保留的已知失败：小素材越侧传播

失败用例：`every_reviewed_body_seam_transports_local_artwork_in_both_directions`，位置为 `next/crates/surface-map/tests/whole_car_cross_coverage.rs:303`。

v24 地图中，从 `su7.front-left-lower-fender` 经 mirrored 接缝传播 300×300 mm、rotation=0.17 的局部素材，覆盖错误到达 `su7.rear-right-door` 和 `su7.rear-right-fender`，触发 `small artwork must not jump across the vehicle`。

接缝 ID：`su7-reviewed-whole-car/front-left-fender--front-left-lower-fender/e3bd7ce49a260cb0/mirrored`。源 primitive=0、sourceTriangle=29084、fragment=`18446640630113911395`，chart 为 `su7.front-left-lower-fender/mirror-right/000`，中心约 `[620.7399292, 67.42333984]`。fragment 为 64 位整数，不用 JavaScript Number 改写地图。

```powershell

```

原算法与失败断言保留。Cargo 在失败目标后退出，不能把未执行的后续目标或文档测试计为通过。另有 `trace_coverage.rs` 的未使用 import 警告，不导致本次构建失败。
