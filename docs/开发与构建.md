# NEXT 开发与构建

2026-11-17 起，所有应用开发在仓库的 `next/` 进行。Rust + Tauri 2 + React / TypeScript + wgpu 为当前架构。

## 环境

现有工作区曾验证 Windows x64、Rust/Cargo 1.97.1、Node.js 24.22.1、pnpm 11.25.0、MSVC C++ Build Tools、Windows SDK 和已安装的 WebView2。依赖以 `next/pnpm-lock.yaml`、`next/Cargo.lock` 为准；迁移整理没有主动升级应用依赖。

## 常用命令

在 `next/` 执行：

```powershell
pnpm install --frozen-lockfile
pnpm desktop:dev
pnpm desktop:build
```

`desktop:build` 生成 `target/release/itasha-desktop.exe`，不制作安装器。根 `启动工作室.cmd` 只启动此发行构建；修改源码后需重新构建。单独 `pnpm dev` 仅启动前端界面预览。

运行 3D 前按 [离线资源](离线资源.md) 恢复独立 SU7 模型。开发构建从 NEXT 的 `assets/paint/manifest.json` 读取运行地图，当前为 `su7-v25-verified/paint-map.json`。独立部署时，除 exe 外还须在其目录或可发现祖先目录保留同一 `assets/paint/...` 相对路径；也可放置于模型包的 `paint/paint-map.json`。旧工程安全迁移另需对应的 v24/v21 旧图，不能仅替换指纹。

## 验证

```powershell
pnpm build
pnpm check:boundary
pnpm test:transforms
pnpm test:editor-properties
pnpm test:whole-layout
cargo fmt --all --check
cargo test --workspace --exclude itasha-desktop --locked
cargo build -p itasha-desktop --features custom-protocol --locked
$env:ITASHA_SMOKE_EXE = 'target/debug/itasha-desktop.exe'
$env:ITASHA_MODEL_ROOT = 'L:/SU7/3D'
pnpm test:desktop
pnpm test:whole-car-seams
```

`ITASHA_MODEL_ROOT` 是桌面测试的可选模型路径，缺省从 NEXT 寻找相邻的 `../../3D`。测试工具只从 NEXT 自身的 devDependencies 加载 Playwright 和 pngjs，不依赖旧 Electron 工作区。smoke 的工程、浏览器数据、截图与报告使用 `next/.reports/` 隔离目录。

跨面专项会核对 manifest、源面遮罩、独立审计报告和真实 GPU 读回；先按 [复查记录](整车跨面复查-2026-11-17.md) 生成同指纹的 `.reports/seam-metric-audit.json`。原越侧传播断言保留，修复前证据见 [主线验证记录](NEXT主线切换-2026-11-17.md)。

## 车型数据与可选工具

正常构建使用已经版本化的 `next/catalog/vehicles.json`。修改目录来源时执行 `pnpm catalog:build`，它读取根 `config/vehicles.json` 和 `vehicles/*/backend-adapter.json`。重新生成前核对已保存工程的 ID 和 catalogVersion 兼容性。

`pnpm inventory`、`tools/legacy/archive-legacy.mjs` 和历代漆面生成脚本是本地资源/历史审计工具，需要另行恢复原始捕获或前代地图；不属于日常构建前提。见 [工具说明](../next/tools/README.md)。
