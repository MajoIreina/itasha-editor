# 开发与构建

## 固定环境

本次环境：Windows x64、Rust/Cargo 1.97.1（MSVC）、Node.js 24.22.1、pnpm 11.25.0。Rust 链接需要 MSVC C++ Build Tools 与 Windows SDK。JS 依赖由 `desktop/pnpm-lock.yaml` 固定，Rust 依赖由 `backend/Cargo.lock` 固定。

Electron 固定为 45.2.3；ImageMagick portable Q16 x64 固定为 7.1.2-35。原生压缩包 SHA256 为 `e7c629f3530ccb9d4918a15f0e928254feda28e84a7fa794b25873d152c075c1`，magick.exe 为 `75d7b9fbaebab840ee71f9631df06659c0b39ff94bdc507cbac772023ff6ce5c`。

在工作区根目录执行：

```powershell
# Git 克隆目录先恢复本地车型资源，已有完整目录只需检查。
node tools/local-assets.cjs --from 'D:\已有完整的痛车编辑器'
node tools/local-assets.cjs --check

# 若 pnpm 不在 Node 旁，先设置 JS 入口路径。
$env:ITASHA_PNPM_CLI = 'C:\实际路径\pnpm\bin\pnpm.cjs'
node tools/setup-desktop.cjs
node tools/build-desktop.cjs
```

setup 从官方固定 release 下载原生依赖，核对压缩包和 EXE 后复制，使用 Windows tar 解包。`--check` 只核对已有依赖；`--native-only` 只处理原生解码器。资源策略在 `config/imagemagick-policy.xml`。

build 编译 release Rust、复制宿主和后端、生成 `desktop/build-manifest.json`。首次替换的旧 EXE 备份到 `development/legacy-webview2`。`examples/` 中的示例仅在 `projects/` 内不存在同名文件时补齐。用户工程与导出不会被构建覆盖。

## 调试与验证

正常启动根目录 `痛车编辑器.exe`。支持环境变量 `ITASHA_ROOT`、`ITASHA_DATA_DIR`、`ITASHA_PROFILE_DIR`、`ITASHA_PORT`。默认数据位于应用目录，浏览器设置在 `app-data-electron`，默认端口 8878，测试端口 0。当前便携目录需可写。

调试运行 `desktop/electron/痛车编辑器.exe --itasha-debug=9233`，仅绑定本机。不要使用 Electron 自身保留的 `--debug`。正常启动不开放调试接口。

```powershell
cargo test --locked --manifest-path backend/Cargo.toml
node --test desktop/test/*.test.cjs tools/test/*.test.cjs
node tools/local-assets.cjs --check
node tools/acceptance-rust.cjs
node tools/acceptance-electron.cjs
node tools/acceptance-launcher.cjs
node tools/acceptance-full.cjs
node tools/camera-navigation-acceptance.cjs
node tools/paint-projection-acceptance.cjs
node tools/surface-curvature-acceptance.cjs
node tools/surface-wrap-bridge-acceptance.cjs
node tools/benchmark-performance.cjs --enforce
```

工具使用独立临时工程与配置，报告在 `tools/acceptance`。性能脚本需要单独运行，避免其他重任务干扰。隐藏模式的 Windows 合成器会降至 1 Hz；性能脚本将窗口显示在桌面之外并保持非激活状态，以取得正常帧计时。测试模式关闭启动失败弹窗。

Git 只保存源码、适配数据与示例，不保存运行时、捕获清单、大型模型、用户工程或机器设置。资源恢复见 [离线资源](离线资源.md)，本地历史归档和提交约定见 [仓库管理](仓库管理.md)。

## 打包

开发打包需要 Python 3.11+ 标准库，Python 不是新应用运行依赖。执行 `python tools/package-desktop.py --check` 验证白名单；不带参数生成 `development/dist/痛车编辑器-0.2.0-便携版.zip`，校验 CRC 并生成 SHA256。

白名单包含宿主、Rust、原生解码器、前端、离线资源、许可、文档及示例工程，排除 target、node_modules、旧 Python/WebView2、缓存、用户工程与浏览器设置。保留了其他车型的离线资源，包体较大。

历史 `tools/build_release.py` 已改为新便携包入口，不使用旧安装器，不覆盖工作区外稳定版发布包。本轮未制作新安装版 EXE。
