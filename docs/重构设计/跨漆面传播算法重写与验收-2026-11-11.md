# 跨漆面传播算法重写与验收

## 范围与结果

本次修复用户反馈的“素材锚定左后门，越过门缝的部分未在左前门显示”。随后按用户要求重写传播计算，保持已分类 PNG/PSD 对应的部件、2D 排布和 2D/3D 映射资产。

活跃映射仍为 `next/assets/paint/su7-v21-classified-only/paint-map.json`：17 个部件、93,356 个三角片、83 条已登记接缝，fingerprint 为 `b16c24a5ff3ba086c545841dd92fd5d0a99ea50ab0cd270b94caca9d8b767db1`。本次没有改动这个文件的坐标、分类、源三角身份或接缝数据。

## 根因

1. 新会话默认关闭跨面，纯 3D 视图没有切换入口；原生文件拖入还强制传入 `cross:false`。
2. 旧传播逐三角使用展开图的共享边长，却用模型真实世界长度构造第三个顶点，两种尺度混合后产生累积变形。
3. 所有接缝同时参与一次三角 BFS。相邻门可从多处进入，并回流锚点门，造成重复图案、顶部多余碎片、局部缺口。

真实模型复现中，旧算法开启跨面后有 674 个后门三角通过“后门→前门→后门”访问，其中 671 个不在关闭跨面时的范围内。旧桌面测试仅改动图层的锚点部件，不能检出同一图层是否同时显示在两面。

## 新传播流程

实现位于 `next/crates/surface-map/src/topology.rs`。

1. 在既有 paint UV 中定位锚点三角；从世界坐标构建毫米物理三角。
2. 仅建立一次物理域到锚点画布坐标的变换。传播全程使用双精度物理坐标，最终用此变换计算素材坐标。
3. 在一个连通曲面内先传播，再选择距离素材中心最近的有效接缝进入邻接曲面。每个连通分量只有一个展开基准，禁止通过邻面回流改写锚点部件。
4. 接缝目标端点按真实世界几何投影，保留目标边的真实长度与切向偏移，不再强行拉伸成源边长。
5. 三角高度使用向量点积、叉积计算，避免瘦三角中的平方差消减。
6. 双精度裁切时携带源三角重心坐标，直接插值原 paint UV 和世界坐标，避免细三角在单精度舍入后逆算失败。覆盖结果仍返回源三角身份、原 paint UV、世界坐标和素材 UV，供 2D 画布、GPU 渲染与命中检测共同使用。

界面在 2D 与 3D 工具栏均提供“跨相邻漆面”，新会话默认开启；选中已有图层时保留该图层的设置。文件拖入继承当前开关。已保存且关闭跨面的图层，需要选中后开启该开关。

## 验证方式

- `classified_door_cross_coverage.rs`：真实 v21 左右前后门双向传播，300/400 mm 素材；检查邻面非空、没有远侧串面、原映射可回投、开关前后锚点部件的完整覆盖结果一致。
- `metric_propagation.rs`：独立几何预期值验证源 UV 非等距/剪切、任意邻面图表、90° 折弯、3 mm 实际缝、不等长接缝边、切向偏移及三部件连续传播。
- 极细三角回归：约百万级图表坐标与约 0.001 mm 窄边组合，验证有限坐标及原三角尖端保留，不以删除细片规避异常。
- `tools/check-door-cross-display.mjs`：实际桌面导入图片并从素材库拖到左后门；同一图层在前后门均可命中，2D 两门都有对应像素；关闭跨面后前门消失、后门保留；保存 GPU 渲染读回图。

## 精度边界

本次消除了旧传播的混合尺度、多入口竞争和回流。它仍是局部曲面展开，不是全曲面无畸变参数化或施工精度认证。当前 v21 源 UV 的局部缩放会保留，因此圆形素材在世界侧视投影中可能呈椭圆。

独立数值复核发现：400 mm 左后门案例中，未作为入口的部分接缝对应点仍有曲面闭合路径残差，最大约 16 mm；这不等同于素材断半、重复或顶部碎片，但不能宣称所有接缝达到毫米级精确对齐。测试过的简单顶点平均与无方向约束平滑会翻转细三角，因此未纳入产品。进一步降低这类误差需要保持三角方向的全局曲面约束求解。
