## 五、性能结论与当前限制

本轮只有 shell 与小草稿功能验收，未测量车型首帧、GPU 帧时间、曲面贴花、4K 输出或大工程保存。
前端构建体积约 228 KB JavaScript、4.56 KB CSS，未压缩；构建体积不等于启动时间或峰值内存。
前述方案的性能区间仍是待验收目标，不能由空 shell 推算已达到的加速比。

当前明确限制：

- 3D 和 2D 区域为状态占位，未接入引擎、模型、拾取、贴花或导出。
- 原生 wgpu 视口尚未验证；不据此冻结渲染承载方案。
- 内部无车型 JSON 草稿不等同于便携工程 v2，不能打开旧 .su7design。
- 同步存储通过 blocking worker 执行，服务锁期间其他工程操作排队。
- 成功请求去重仅在当前进程内有效；重启不会恢复撤销栈和未保存修改。
- 损坏工程会令当前列表读取明确失败，尚无逐项隔离/修复 UI。
- 安装器、签名、旧版资源迁移和全量异常恢复未实现。
