# 界面主题

在「设置 → 工作区 → 外观主题」选择深色（白字）、浅色（黑字）或跟随系统。默认深色。应用设置后保存到 Rust 管理的本机设置；取消不改变当前主题。

`Settings.theme` 为 `dark | light | system`，Rust 使用枚举拒绝未知值，旧设置缺少字段时默认深色。欢迎、加载设计、车型选择、车型选配、工作区、左右工具栏与弹窗共享 CSS 语义色板，使用 Windows 11 风格的中性灰表面与蓝色强调色（浅色 #0078D4，深色 #60CDFF），去除主题中的绿色背景、边框、焦点环及示意图配色。车漆选项本身的颜色不受主题改变影响。

React 根据已保存的偏好设置根节点 `data-theme`，仅在跟随系统时订阅 `prefers-color-scheme` 的变化，切换或卸载时清理订阅。原生窗口主题同步使用 Tauri 的窗口主题设置；跟随系统传入 `None`。

验证包括：旧设置迁移、三种枚举序列化与非法值拒绝；真实 Tauri/WebView2 窗口中切换并重新加载设置；通过浏览器媒体偏好模拟系统深浅切换，检查实时响应和显式主题优先级；截图检查浅色欢迎页、工作区及设置。系统切换测试使用媒体偏好模拟，未修改测试机器的 Windows 全局主题。
