# NEXT 抗锯齿实现与验收

入口：**设置 → 性能 → 抗锯齿**。设置立即应用并持久化，默认仍为 FXAA。

## 模式约定

| 模式 | 内部尺寸（基于所选渲染比例） | 实现 | 开销特点 |
| --- | --- | --- | --- |
| 关闭 | 1× 宽、1× 高 | 直接输出 | 最低 |
| FXAA | 1× 宽、1× 高 | 当前帧边缘平滑 | 轻量，默认 |
| TAA | 1× 宽、1× 高 | 8 相位抖动、深度重投影、历史融合 | 增加历史纹理和时域解析 |
| TAA 2x | 2× 宽、2× 高 | 高分辨率 TAA，再缩小输出 | 4 倍内部像素量，额外历史纹理 |
| SSAA（2×） | 2× 宽、2× 高 | 空间超采样、线性颜色空间面积采样 | 4 倍内部像素量，无历史帧 |

这里的“2x”明确指两个轴各两倍，并非两倍总像素。尺寸先根据 50% / 75% / 100% 渲染比例取整，再应用倍率。例如 50% + TAA 2x 的内部尺寸约等于输出尺寸；100% + TAA 2x 的内部像素量为输出的四倍。最终窗口、UI 和编辑手柄仍使用输出尺寸。

## 渲染与交互

- Halton 采样序列对完整 8 帧进行中心化，避免静止结果长期偏移。
- 当前颜色为抖动相机渲染，重投影运动使用未抖动的当前/上一帧矩阵；静止时历史查找位置保持稳定。
- 历史颜色使用 RGBA16F，历史线性深度使用 R32F，双缓冲交替读写。使用深度拒绝和 YCoCg 邻域/方差裁剪限制拖影。
- 地面、天空和透明材质当前没有独立运动矢量。移动相机时拒绝无深度背景的历史，并降低移动帧历史权重；这不等同于完整透明物体运动矢量方案。
- 模型、图层、素材纹理、投影贴图、设置、主题、输出尺寸、视角复位或定位发生变化时清除历史。连续相机运动重新计数静止收敛帧；大幅视角变化直接丢弃旧历史。
- 静止后累计 8 次成功绘制即停止额外刷新；交换链未取得输出帧时不推进历史采样。
- 拾取射线、漆面坐标映射、素材控制点均采用未抖动矩阵。控制点在抗锯齿解析完成后按输出分辨率单独绘制。
- TAA 着色器管线、布局、采样器缓存复用。拖动双视图分隔条时仅重建尺寸相关纹理及绑定；离开 TAA 模式释放历史纹理。

## 尺寸与资源预算

内部尺寸同时受 `device.limits().max_texture_dimension_2d` 和单组渲染附件 **256 MiB** 预算约束，按相同比例缩小两个轴；触发限制时状态栏提示。预算不包含模型贴图、交换链和调整尺寸期间仍在 GPU 队列中的旧附件，不能视为整个应用的显存上限。

按内部像素计算，普通颜色/深度附件约 8 字节，TAA 加双份历史颜色/深度后约 32 字节。以 1920×1080、100% 比例为例，FXAA/关闭约 15.8 MiB，TAA 约 63.3 MiB，SSAA 约 63.3 MiB，TAA 2x 约 253.1 MiB。更高分辨率可能触发预算限制。

这些倍率说明像素处理和附件存储量，不代表整帧时间按倍率增加。完整 GPU 帧耗时仍取决于模型、材质、视口大小及显卡；现有 `lastSubmitCpuMs` 只记录 CPU 提交时间。

## 验证

自动验证包含：所有模式的配置往返与无效值拒绝、采样序列中心化、静态重投影不变量、历史收敛与重置、尺寸/显存限制、实际 GPU 颜色截图、超采样尺寸、无空白画面、漆面拾取稳定、场景昼夜切换后的历史失效和静止停止刷新。

首轮 Release 验证：RTX 5080 / Vulkan，输出 914×436；TAA 内部 914×436，TAA 2x / SSAA 内部 1828×872。两种时域模式各提交 8 帧后停止刷新，SSAA 提交 1 帧。CPU 单帧提交记录约 0.73–1.09 ms；含设置 IPC 和测试轮询的观测等待约 214–225 ms，**这些值均不是 GPU 帧时间或实际 FPS**。

首轮证据：`next/.reports/smoke-1794412702431/antialiasing.json`，配套模式 PNG 为原生 wgpu 输出回读。核心测试共 68 项通过，首轮桌面回归 31 项通过。

最终 Release 加入管线缓存后，桌面回归 **33 项全部通过**，证据位于 `next/.reports/smoke-1794412944250/result.json`。新增专项覆盖 TAA 2x 分隔条拖动期间 3D 持续显示、目标尺寸重建后收敛，以及 TAA 下 2D 素材旋转和原生 3D 缩放/旋转/取消；所有操作完成后恢复空闲停止刷新。复核核心渲染测试 18 项通过，前端构建、源码边界检查、编辑变换检查通过。

最终程序：`next/target/release/itasha-desktop.exe`，20,938,240 字节；SHA-256：`8a0a2731acc70a9363a111a170f36995c5f965677521213490acc41aab10a8e2`。后续构建会改变此校验值。

## 主要代码

- `next/crates/renderer/src/gpu/temporal.rs`：模式、尺寸预算、历史状态、GPU 资源与管线缓存。
- `next/crates/renderer/src/gpu/temporal.wgsl`：深度重投影、历史拒绝、邻域裁剪与融合。
- `next/crates/renderer/src/gpu/effects.rs`、`post.wgsl`：时域解析与最终缩小输出。
- `next/crates/renderer/src/gpu.rs`、`next/src-tauri/src/platform/viewport.rs`：相机矩阵、编辑失效、按需帧调度及状态。
- `next/crates/contracts/src/lib.rs`、`next/src/features/settings/SettingsPanel.tsx`：配置校验和用户选项。
- `next/tools/smoke/smoke-desktop.mjs`：原生 GPU 截图及桌面回归。
