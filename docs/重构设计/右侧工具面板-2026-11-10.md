# 右侧工具面板增量

日期：2026-11-10

工作区右侧保留工程属性，新增素材库、图层管理、插入图形、插入文字四个独立面板。

- 每个面板标题右侧支持最小化/恢复，恢复保留之前高度。
- 面板底部边界可拖动调整内容高度，范围 100–800 px。
- 边界支持上下方向键（10 px）、Shift 加方向键（50 px）、Home/End，双击恢复默认高度。
- 工具区提供重置布局；外层及每个面板内容区分别支持滚动。
- 拖动时只更新 React 预览，释放后通过原有 settings 命令保存一次。
- Rust WorkspaceSettings.panels 持久化高度与最小化状态，校验面板 ID 与范围。旧配置缺失字段时按默认布局读取。

素材导入、图层编辑、图形插入和文字排版尚未接入编辑服务，本次提供面板容器与布局行为，相关业务控件明确禁用。不会产生虚假图层或伪保存内容。
工程名称、基础选配与放弃未保存修改保留在可调整的工程属性面板内。
