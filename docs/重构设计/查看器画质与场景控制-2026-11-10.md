# 查看器画质与场景控制：0.3.0-dev.6

本次实现抗锯齿、有效的分辨率与帧率设置、相机限位、程序化天空盒及场景时间。设置保存于本机，不改变工程内容、图层和撤销历史。

## 使用入口

- 设置 → 性能：抗锯齿可选关闭或 FXAA，默认 FXAA；目标帧率 30/60/120；渲染分辨率 50%/75%/100%。应用设置后立即生效，无需重新加载车型。
- 设置 → 场景：开启/关闭天空盒，通过滑条或精确时间输入调整 00:00–23:59，可快速选择日出、正午、日落和午夜。默认开启天空盒、14:00。
- 时间同时影响天空色、太阳方向/颜色/强度、车身直接光、贴花照明与解析环境反射。选中蓝色边缘和控制点保持可见。关闭天空盒仅切换背景为主题底色，保留时间光照。

旧设置缺少新增字段时自动使用上述默认值。未知抗锯齿模式和超出 0–1439 的分钟值被 Rust 拒绝。纹理上限仍在模型重新加载时生效；缓存预算仍是预留偏好，未声称已接通。

## 渲染与性能实现

场景先渲染到按比例缩放的颜色/深度附件，再使用全屏 pass 做 FXAA 或直接采样并输出到原生窗口。控制框与操作点在输出原始分辨率上单独绘制，拾取使用原始窗口坐标，分辨率设置不会改变编辑坐标。

FXAA 使用局部亮度对比、边缘方向和沿边采样平滑轮廓，低对比区域提前结束。它不需要多采样深度附件，但增加一个全屏处理 pass，细小文字或纹理可能变柔。当前不提供 MSAA、TAA 或时间累积；不能将 FXAA 描述为无成本。

渲染分辨率按宽、高同时缩放：75% 对应约 56.25% 的场景像素，50% 对应约 25%，这是像素数量变化，并不代表总帧耗时同比下降。最终输出和控制点仍为窗口分辨率。新增颜色附件占用约 4×内部宽×内部高字节，另有同尺寸深度附件。

原生事件循环使用已保存的目标帧率控制脏帧调度；按帧起始时间计算间隔，避免将渲染耗时再额外累加到帧间隔。FIFO 呈现仍受显示刷新率和 GPU 负载限制，设置 120 不是 120 FPS 保证。静止、隐藏及模态遮挡时保持按需绘制。拖动工程库或分屏边界期间隐藏原生子窗口，避免抢走指针事件；隐藏时延后 GPU 尺寸重建，恢复可见后按最终尺寸创建。没有选中素材时不再为零个控制点分配 GPU 顶点缓冲。

## 相机与天空

相机俯仰角限制在 0.01–1.45 弧度；常规滚轮距离限制在模型包围球半径的 0.45–4 倍。定位素材可使用 0.3 倍的近距下限。平移目标约束在初始中心周围一个包围球半径内，目标高度不低于模型底部 0.05 米；最终渲染前再次约束，保证观察点高于地平线。窄窗口的适应距离系数最多 2.5，防止极端比例导致无限远退。

天空使用逆相机矩阵重建方向，程序化计算天顶、地平线、太阳盘及地平线下方颜色，随视角正确旋转，不依赖外部 HDR 贴图。太阳轨迹是展示用 24 小时周期：06:00 日出、12:00 正午、18:00 日落。当前不是按经纬度/季节计算的天文模拟，也没有实体地面、接触阴影、HDR 预过滤 IBL 或可导入天空资源。
