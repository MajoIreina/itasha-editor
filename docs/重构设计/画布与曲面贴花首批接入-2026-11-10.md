# 画布与曲面贴花首批接入

日期：2026-11-10。版本：0.3.0-dev.4。对应阶段 3 的首批可运行增量，未达到阶段 3 的全部退出条件。

## 本次交付

工作区 2D 画布已连接 Rust 工程状态和原生 wgpu 预览。可插入矩形、椭圆、三角形、直线、星形、六边形、文字和本机图片；支持选择、移动、缩放、旋转、显隐、锁定、复制、层序和删除。右侧工具面板沿用软件自身的 Win11 深浅主题、尺寸调整和最小化交互。

拖动仅在 React 画布中预览，松开提交一次领域操作；Esc 或 pointercancel 取消。Shift 保持缩放比例或使用 15° 旋转步进。保存、重开、撤销与重做覆盖图层内容及映射，不仅覆盖工程名称。

前后 C 环采用独立编辑面，其当前标准套件使用 carPaint_sameColor_MT，同样属于车漆范围。未来开放黑化或碳纤维套件时，必须同步调整材质识别与贴花权限；当前尚无该套件的选配入口。

映射配置由同一份 SurfaceSpec 提供节点、名称和投影轴，消除两份数组按位置配对的风险。每个来源均为 primitive/0；几何、轴和部件 ID 计算 surfaceFingerprint。工程保存该指纹，指纹不匹配时停止编辑映射，禁止静默套用到不同几何。

## 2D 与 3D 的关系

Rust 根据原始变换后网格生成朝向有效的三角面投影与毫米尺寸，再以二进制 float32 发送遮罩。2D 使用同一投影范围裁切，C 环中心空洞保留。前后、左右使用不同投影轴，避免直接复用导致镜像。

3D 在原车网格的片元着色器中计算投影坐标并采样合成贴花，保留真实曲面、深度和接缝；没有额外悬浮平面。每个部件独立纹理，未开放部件绑定透明纹理。贴花与原车漆进行颜色、金属度与粗糙度混合。

这是按部件的正交曲面投影，尚非物理展开。朝向阈值为 dot(normal, projectionNormal) > 0.15，接近侧向的急弯端部可能被排除或拉伸；2D 遮罩使用面法线、3D 使用插值法线，阈值附近也存在覆盖差异。尚不支持跨部件连续包覆、曲率畸变补偿、3D 点选定位、施工尺寸导出。后续需以参数化曲面/网格锚点及畸变验收补足。

## 状态、持久化与资源预算

Rust 是图层与修订的权威来源。修改校验 project/session epoch/expectedRevision；锁定层拒绝移动和删除。历史包含名称、图层元数据与 contentId，最多 100 条且限制序列化元数据总量 16 MiB；撤销恢复已保存 contentId 时回到干净状态。历史不跨重开持久化。

图层最多 200 个，素材最多 128 个。PNG/JPEG/WebP 经本地 Rust 解码、规范化为 PNG，以 SHA-256 命名存入 blobs/，工程仅引用摘要与尺寸。输入上限 20 MiB、单边 8192、单图 16,777,216 像素、总计 67,108,864 像素；内部工程元数据上限 8 MiB。打开/保存检查引用素材完整性。尚无素材垃圾回收和便携打包，避免删掉撤销仍可能引用的素材。

提交后前端等待 80 ms 合成受影响部件，再发送原始 RGBA，预览长边最多 1024；不逐 pointermove 传图。前端只保留一个在途任务和最新待处理快照，原生队列按部件合并，校验会话、场景 generation 和权威修订；GPU 接受更新后返回确认，过期任务不能标记为已同步。该路径为提交后的预览同步，尚未承诺实时拖动中的 3D 反馈或高分辨率最终输出。
