# 左侧工程库布局增量

日期：2026-11-10

- 拖动工程库右边界调整宽度，范围 160–360 px。
- 向左拖至侧栏起点 64 px 内，吸附为 34 px 窄栏；保留“工程库”标识和展开按钮。
- 展开恢复收起前宽度，也可从窄栏右边界向右拖动展开。
- 标题右侧按钮支持直接最小化。边界双击恢复 214 px 默认宽度。
- 边界支持左右方向键（10 px）、Shift 加方向键（40 px）、Home 收起、End 最大宽度。
- 取消拖动不保存；释放后通过 Rust 设置一次性保存 libraryWidth / libraryMinimized。
- 旧配置自动补充默认值，工程数据与 dirty 状态不受布局变化影响。

验证：17 项 Rust 测试、前端生产构建和真实 Tauri smoke 通过。
