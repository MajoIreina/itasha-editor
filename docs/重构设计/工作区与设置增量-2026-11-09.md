# 工作区与设置增量

日期：2026-11-09

本增量在 next/ 内实现。旧版和用户数据不迁移。

## 交互

- 双视图可在工具栏切换上下/左右排列，单独的 3D / 2D 模式保留。
- 分隔条支持拖动，3D 占比限制 25%–75%；方向键每次 1%，Shift 加方向键每次 10%，Home/End 到边界，双击恢复 65%。
- 拖动只更新本地视图，释放时写入 Rust 设置，避免逐 pointermove IPC 和磁盘写入。
- 右上角设置提供工作区、性能、快捷键、路径四个分类，修改后统一应用，取消不写入；关闭有修改的设置时提示放弃。
- 设置为原生 dialog，支持 Escape、焦点约束与关闭后焦点恢复。

## 设置契约

沿用 schemaVersion 1，新增 workspace、performance、shortcuts、paths 四个字段；旧文件缺少这些字段时读取默认值，旧布局保持。
全量设置由 Rust 校验后替换写入；参数、冲突或目录检查失败不会覆盖已有文件。
不支持的字段仍拒绝，以免错误配置被静默忽略。

| 分类 | 字段与约束 | 生效范围 |
| --- | --- | --- |
| 工作区 | 上下/左右、25–75% 比例、双视图/3D/2D | 立即生效并持久化 |
| 性能 | 30/60/120 FPS、50/75/100% 渲染比例、1024–8192 纹理边长、256–16384 MB 缓存 | 保存偏好；渲染器接入后生效 |
| 界面 | 减少动态效果 | 立即生效，同时遵循系统偏好 |
| 快捷键 | 保存、撤销、重做、设置；Ctrl + 可选 Shift + 字母/Comma | 立即生效；重复组合拒绝 |
| 路径 | 模型、导出、缓存目录 | 保存偏好，消费模块接入后使用 |

保存默认 Ctrl+S，撤销 Ctrl+Z，重做 Ctrl+Shift+Z，设置 Ctrl+逗号。
使用物理按键 code 识别，IME composition、Alt/Meta 组合和已处理的事件不触发应用快捷键。
文本输入中的撤销/重做交给文本框；设置对话框打开时停用工程快捷键。
按住组合键重复触发的行为受应用串行 busy 保护。

路径可手动输入绝对路径或使用原生目录选择器。仅选择，不移动、删除或复制文件。
非空路径必须为已存在目录；模型目录检查读取，导出和缓存目录另用临时文件检查写入。
留空表示后续模块采用应用数据目录下的默认子目录。
工程与设置目录只读展示，现阶段不支持切换工程根目录或自动迁移。
原生目录选择由宿主限定命令 choose_directory 执行，主窗口 capability 显式授权，未开放任意文件读写插件权限。
