## 完成范围

- React 由扁平目录迁入 `app/`、`features/`、`bridge/`、`shared/`，根 `main.tsx` 仅保留挂载。颜色组件样式独立，快捷键工具放入共用输入模块，避免功能层反向依赖应用装配层。
- Tauri `main.rs` 缩为 34 行；服务装配迁入 `host.rs`，20 个 IPC 分入 `commands/editor.rs`、`assets.rs`、`viewport.rs`；原车型适配和原生视口分别迁入 `adapters/su7.rs`、`platform/viewport.rs`。
- 37 个工具分入 `checks/tests/smoke/catalog/assets/legacy`；同步 package scripts、相对源码引用、Python helper 和脚本工作区根定位。
- 真实桌面方向测试原先读取本机保留的 v22 地图；现改用仓库版本化的当前 v24，移除这一隐藏依赖。
- 补充结构与开发入口说明，同步根 README、NEXT README、AGENTS、架构说明和已有文档链接。

`next/` 路径、6 个 Rust crate、IPC 名称/注册顺序、权限、契约和锁定依赖保持。两个原生大文件迁移前后 SHA-256 完全相同，前端业务正文经排除导入/入口提取后对比一致。未修改漆面地图、资产清单或用户数据。
