# NEXT 离线模型资源

源码仓库不包含原始捕获、解密原件、GLB、贴图、Blender 工程或第三方运行时。现有完整 SU7 基线为本机 `L:/SU7/3D`，处理后的软件包为 `L:/SU7/3D/Blender/software`。

## 模型包

恢复软件包中的 `config.json`、`body.glb`、选配轮组/方向盘 GLB 与 `textures/`，保持配置中的相对引用。应用设置可选择 `3D`、`Blender/software` 或直接的软件包目录。

运行时依次尝试设置路径、其中的 `Blender/software` 或 `software`；未指定路径时从 exe 祖先查找 `3D/Blender/software` 或 `models/su7`。不会自动下载缺失资源，也不从旧 Electron 引擎加载模型。

可选清点命令，在 `next/` 执行：

```powershell
node tools/assets/audit-model-package.mjs 'L:/SU7/3D/Blender/software'
cargo run -p itasha-renderer --example verify_paint_package -- 'L:/SU7/3D/Blender/software' assets/paint/su7-v24-mirrored/paint-map.json
```

## 漆面映射

当前 `assets/paint/su7-v24-mirrored/paint-map.json` 随源码版本化。独立部署时须连同 exe 保留可发现的 `assets/paint/su7-v24-mirrored/paint-map.json`，或放进模型包的 `paint/paint-map.json`。只复制 exe 不构成完整可运行包。

映射文件、模型和工程指纹必须对应。当前 fingerprint 和文件哈希见 [映射说明](../next/assets/paint/README.md)。v24 左前下翼子板含镜像近似，不能当作厂商原生展开；已知传播回归见 [验证记录](NEXT主线切换-2026-11-17.md)。

车型目录生成的来源数据保留于根 config/vehicles。原配置器捕获和历史地图只供可选离线工具，不是 NEXT 日常运行依赖。
