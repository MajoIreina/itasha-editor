# 离线资源恢复

源码仓库不包含约 4.3 GiB 的离线车型存档，也不包含 Electron 和 ImageMagick 运行时。已有完整本地目录保持原状；从 Git 克隆新目录时按下面步骤恢复。

## 从已有完整目录导入

```powershell
# 查看计划，不复制。
node tools/local-assets.cjs --from 'D:\已有完整的痛车编辑器' --dry-run

# 只复制缺失的车型存档文件。
node tools/local-assets.cjs --from 'D:\已有完整的痛车编辑器'

# 校验本地清单及其引用的文件是否齐全。
node tools/local-assets.cjs --check
```

来源必须是包含 `resources/manifest.json` 和已注册车型捕获清单的完整目录。脚本按照仓库中的车型注册表收集清单、清单引用的本地资源、配置缩略图和补充车型元数据，不复制 `projects/`、`exports/`、浏览器配置、日志、令牌或运行时。

导入前先核对整个来源，文件不存在时才复制。目标已有清单若内容不同会停止；已有资源大小不同也会停止，避免混用两个存档。`--check` 验证引用和文件大小，不做完整内容哈希，也不保证其他车型已经通过编辑适配。

## 运行依赖

`node tools/setup-desktop.cjs` 安装锁定的 Electron / JS 依赖及 ImageMagick，`node tools/build-desktop.cjs` 构建 Rust 后端和启动器。详见 `docs/开发与构建.md`。

车辆模型、材质与配置器存档继续保持原有来源和许可关系。它们是运行资源，不因存放在本地而成为本仓库原创源码。
